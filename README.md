# PPE Guard

사내망 환경을 전제로 하는 PPE 점검 데스크톱/백엔드 프로젝트입니다.

구성:

- `frontend`: PySide6 데스크톱 클라이언트
- `backend`: Flask API + Socket.IO + 서비스 DB
